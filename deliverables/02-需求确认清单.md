# 奢侈品独立站 · 需求确认清单

> 用法：带到跟客户的沟通会上逐条问。每条都标了「为什么问」和「不同答案带来的影响」——
> 前者帮你问得专业，后者帮你在现场就能判断工作量和风险。
> **第 2 节（收款主体与支付）没问清楚之前，不要报价。**

---

## 1. 商业与市场

- [ ] **品牌主体是谁？是品牌方本人，还是经销商/买手？**
  - 为什么问：奢侈品行业大量存在"非品牌方卖品牌货"的情况，这直接决定授权材料能否拿到。
  - 影响：经销商/买手 → 支付通道风控风险显著上升，可能需要额外证明材料。

- [ ] **目标市场国家/地区清单？主力市场是哪个？**
  - 为什么问：支付方式、税率、关税模式、语言全部由市场决定。
  - 影响：
    - 北美 → Stripe/PayPal/Braintree；Sales Tax nexus 规则
    - 欧洲 → Stripe 强制 SCA/3DS；VAT 必须合规
    - 中东 → Checkout.com/PayTabs/Tap；可能需要阿拉伯语 RTL
    - 多市场 → 需多币种 + 多语言，工作量翻倍

- [ ] **是 B2C 零售，还是含 B2B 批发？**
  - 为什么问：B2B 需要分级定价、账期、询盘流程，是完全不同的产品形态。
  - 影响：含 B2B → 需要额外插件与流程设计。

- [ ] **客单价区间大概是多少？**
  - 为什么问：**这是奢侈品项目的核心风险指标。**
  - 影响：客单价越高，支付通道风控越严、资金冻结风险越大、支付失败率对营收影响越大。需要更严格的支付兜底与风控策略。

- [ ] **上线后预计的商品 SKU 数量与更新频率？**
  - 为什么问：决定商品导入工作量与运维复杂度。

---

## 2. 收款主体与支付（**最关键，先问这一节**）

- [ ] **用哪个公司主体收款？注册地在哪？**
  - 为什么问：**这是"打通支付通道"的真正卡点。** 大陆主体开 Stripe 基本不可行；PayPal 对主体与注册地也有要求。
  - 影响：
    - 香港/新加坡/美国主体 → 可以直接申请，方案顺畅
    - 仅大陆主体 → 需走聚合收单（Airwallex / 万里汇 / PingPong / Asiabill 等），或先注册境外主体；产品落地周期与成本都会变

- [ ] **客户明确说用 PayPal——那要追问：PayPal 商业账户是哪个国家注册的？**
  - 为什么问：PayPal 商业账户的注册国决定了可提现币种、结算路径与 Seller Protection 范围。
  - 影响：账户国与目标市场不一致 → 会出现货币转换损耗、提现限制、部分市场买家不信任该通道。

- [ ] **是否已有其他支付通道账户？是否被拒过？**
  - 为什么问：奢侈品/时尚类目被通道拒批很常见，历史被拒记录会影响后续申请策略。
  - 影响：曾被拒 → 必须做备选通道方案，并在报价里单列"通道申请协助"。

- [ ] **能否提供品牌授权文件、进货发票、品牌官网佐证？**
  - 为什么问：通道承保（underwriting）审核奢侈品必查。这是**唯一能降低被拒概率的杠杆**。
  - 影响：材料齐全 → 通道大概率能过；材料缺失 → 高概率被拒，项目直接阻塞。

- [ ] **客户是否了解高客单价 + 新账户容易出现资金冻结（fund hold）？**
  - 为什么问：新 PayPal/Stripe 账户接高额订单，风控常做 21 天资金留存。客户不知道会以为是你没做好。
  - 影响：必须提前书面告知，让客户预留周转资金。这条不提前说，上线后一定扯皮。

- [ ] **支持的结算币种与展示币种有哪些？**
  - 为什么问：展示多币种 ≠ 结算多币种，两者要分开确认，避免汇兑损失争议。

- [ ] **是否需要分期付款 / 先买后付（Klarna、Afterpay）？**
  - 为什么问：欧洲和中东的分期需求很普遍，直接影响支付方案与插件选型。

## 3. 商品与履约

- [ ] **商品从哪里发货？自发货、3PL 海外仓、还是工厂直发？**
  - 为什么问：决定运费规则、时效承诺与物流对接复杂度。
  - 影响：3PL/海外仓 → 需对接其 WMS API，工作量显著上升。

- [ ] **用哪些承运商？是否已有账号与 API 凭证？**
  - 为什么问：物流轨迹自动回传的前提。
  - 影响：有凭证 → 可做 API 直连；无凭证 → 只能手动填运单号 + 聚合查询，体验降级。

- [ ] **是否需要保价、强制签收、白手套配送？**
  - 为什么问：奢侈品标配，且影响运费计算与承运商选择。

- [ ] **关税由谁承担？DDP（卖家包税）还是 DDU（买家自付）？**
  - 为什么问：奢侈品客单价高，关税金额敏感，直接影响结账页设计与客户投诉率。
  - 影响：DDP → 需要预收关税，结账页与运费规则复杂度上升。

- [ ] **退换货政策是什么？是否需要退货标签自动生成？**

---

## 4. 合规与法务

- [ ] **是否需要税务顾问配合处理 VAT / Sales Tax？**（你只负责技术实现提示，不承担税务责任）
- [ ] 隐私政策、Cookie 同意（GDPR / CCPA）、退换货条款由谁撰写？
- [ ] 是否需要年龄验证（部分品类/地区）？
- [ ] 目标市场是否有针对奢侈品/进口商品的特殊资质要求？

---

## 5. 技术与集成

- [ ] **是否需要对接 ERP / CRM / 库存系统？具体是哪一套？**
  - 为什么问：这是工作量最容易失控的部分。
  - 影响：有对接 → 视对方是否有 API 及文档质量，可能占据整个项目 30%+ 工作量。

- [ ] 现有域名、主机、SSL、邮箱是否已就绪？是否从旧站迁移？
- [ ] 是否已有分析工具（GA4 / GTM / Meta Pixel）需要埋点？
- [ ] 是否需要 CDN、图片处理（奢侈品高清大图，性能压力大）？
- [ ] 是否需要多语言？具体语言清单？（中东需 RTL 支持）

---

## 6. 内容与设计

- [ ] **品牌视觉素材（Logo、VI、字体）是否已有？**
  - 为什么问：很多奢侈品客户以为"做个站"包含"做品牌设计"。
  - 影响：无素材 → 必须明确列为不含项或单独报价。

- [ ] 商品图片与文案是否齐备？由谁提供？
- [ ] 是否有已确定的视觉参考站（竞品/风格对标）？
- [ ] 谁负责页面文案与翻译？

---

## 7. 上线与运维

- [ ] 期望上线时间？是否有硬性节点（如某个营销活动）？
- [ ] 上线后由谁运维？是否需要你提供年度运维？
- [ ] 是否需要培训？培训人数与形式？
- [ ] 是否接受分阶段上线（先跑通支付，再补物流自动化）？

---

## 8. 沟通与决策机制

- [ ] 谁是最终决策人？谁是日常对接人？
- [ ] 沟通渠道与语言？（客户是否说英文？是否需要英文书面沟通）
- [ ] 例会节奏与反馈时效承诺？
- [ ] 变更需求走什么流程？

---

## 使用建议

1. **先问第 2 节**，把收款主体和品牌授权问清楚——这两个答案决定项目可行性。
2. 把每条的答案直接填进《报价模板与SOW》的 **C3 客户前提**表和 **C6 风险表**。
3. 任何一条客户答不上来，就在报价里写成"待确认，确认后可能调整报价"，而不是自己猜着报。
4. 目标市场还没定的情况：**先按通用方案报价，并注明"多市场适配按市场数量阶梯计价"**，避免后面无限加市场却不加钱。
